## About Us

**BigBrainDevBros** is a collaborative engineering organization focused on building fast, local-first, zero-telemetry software—ranging from browser-native multiplayer games to native macOS utilities, extensions, and CLI tools.

### Featured Organization Projects

- **[RenYing](https://github.com/BigBrainDevBros/RenYing)** — Ink-wash martial-arts fighting game in the browser with 36 heroes, serverless WebRTC P2P rollback netplay, and an optional Cloudflare Worker backend.

### Core Engineering Principles

- **Local-First & Zero Telemetry:** Complete client-side ownership with no tracking bloat.
- **High-Craft Performance:** Native platform APIs and lean web bundles built for speed.
- **Clean Engineering Hygiene:** Automated CI, reproducible builds, and clear documentation across every repository.
