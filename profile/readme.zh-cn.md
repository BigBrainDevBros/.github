## 关于我们

**BigBrainDevBros** 是一个协作工程组织，专注于构建快速、本地优先、零遥测的开源软件，涵盖浏览器多人对战游戏、原生 macOS 工具、浏览器扩展与命令行工作站。

### 核心组织项目

- **[FaceOff](https://github.com/BigBrainDevBros/FaceOff)** · [在线游玩](https://bigbraindevbros.github.io/FaceOff/)：九胜制第一人称浏览器竞技场对战，支持四张地图、四档 AI 难度与联机房间。
- **[RenYing（刃影）](https://github.com/BigBrainDevBros/RenYing)** · [在线游玩](https://bigbraindevbros.github.io/RenYing/)：水墨武侠浏览器格斗游戏，拥有 20 位特色侠客、无服务器 WebRTC P2P 回滚联机与可选 Cloudflare Worker 云端存档。
- **[VANTAGE](https://github.com/BigBrainDevBros/VANTAGE)** · [在线游玩](https://bigbraindevbros.github.io/VANTAGE/)：由 HilbertQiu 主导的程序化城市 3D 射击游戏，支持百人 AI 对局与 1v1 / 合作联机。

### 工程与协作原则

- **本地优先与零遥测**：完整客户端数据掌控，无多余追踪膨胀。
- **高性能与精良工艺**：充分利用原生平台与轻量 Web 构建。
- **清晰工程规范**：自动化 CI、语义化版本控制（`MAJOR.MINOR.PATCH`），以及 [规范模板](../template.md) 与 [合规清单](../check.md) 约束。
- **跨仓库协作**：团队成员可通过 [GitHub Discussions](https://github.com/orgs/BigBrainDevBros/discussions) 与跨仓库建议模板快速交流想法。
